## پاسخ‌ها

### 01 — هدف اصلی Prototype
**وضعیت:** تصمیم ثبت شد

**پاسخ:**

هدف Prototype دو بخش اصلی دارد:

1. **ارزیابی توانایی مدل و سیستم:** بررسی اینکه مدل برای کارهایی که قرار است انجام دهد چقدر توانایی دارد، کیفیت خروجی آن چگونه است، و خروجی‌ها تا چه اندازه امن و قابل اعتماد هستند.
2. **ساخت یک Base قابل استفاده مجدد:** Prototype باید یک پایه عملی و قابل اتکا ایجاد کند تا در آینده بتوان قابلیت Local AI را راحت‌تر و با ریسک کمتر در پروژه **WooGit** پیاده‌سازی کرد.

بنابراین پروژه فقط یک Chat Demo نیست؛ یک محیط آزمایشی برای ارزیابی **Capability، Safety/Reliability و قابلیت انتقال معماری به WooGit** است.

### 02 — مدل پایه
**وضعیت:** تصمیم ثبت شد

**پاسخ:**

مدل پایه برای طراحی و توسعه Prototype، **Qwen3-1.7B** است.

این انتخاب به‌عنوان مدل مرجع طراحی انجام شده است، اما مدل نباید داخل APK بسته‌بندی شود. فایل مدل باید جداگانه تهیه و توسط کاربر در اپ **Import** شود.

معماری باید از ابتدا به‌صورت **Model-Agnostic** طراحی شود؛ یعنی Qwen3-1.7B مدل پایه و مدل هدف فعلی باشد، اما ساختار Import/Validation/Loading/Inference به یک مدل خاص قفل نشود تا در آینده بتوان مدل‌های سازگار دیگری را نیز بدون بازطراحی اساسی اپ وارد و اجرا کرد.

**اصل تصمیم:**
- مدل پیش‌فرض/مرجع: Qwen3-1.7B
- مدل داخل APK: خیر
- دریافت مدل: جداگانه
- ورود مدل به اپ: Import
- قابلیت Import مدل‌های آینده: الزامی
- وابستگی معماری به یک مدل خاص: ممنوع

### 05 — روش Import مدل
**وضعیت:** تصمیم ثبت شد

**پاسخ:**

مدل باید **جدا از APK** تهیه شود و کاربر آن را مستقیماً از طریق قابلیت **Import Model** وارد اپ کند.

فرآیند موردنظر:

1. کاربر گزینه **Import Model** را انتخاب می‌کند.
2. فایل مدل را از حافظه/Files دستگاه انتخاب می‌کند.
3. اپ فایل را بررسی و اعتبارسنجی می‌کند.
4. مدل به فضای اختصاصی مدیریت مدل‌های اپ کپی/ثبت می‌شود.
5. مدل در فهرست مدل‌های قابل استفاده نمایش داده می‌شود.
6. کاربر می‌تواند مدل را Load کرده و برای Chat/Inference استفاده کند.

این سیستم باید از ابتدا عمومی طراحی شود تا بعداً مدل‌های سازگار دیگر نیز با همین فرآیند قابل Import باشند و معماری به Qwen3-1.7B وابسته نشود.

**اصل تصمیم:**
- مدل داخل APK: خیر
- دریافت مدل: جداگانه
- ورود مدل: Import توسط کاربر
- اعتبارسنجی قبل از استفاده: الزامی
- نمایش مدل‌های Import‌شده: الزامی
- پشتیبانی از مدل‌های آینده: الزامی
