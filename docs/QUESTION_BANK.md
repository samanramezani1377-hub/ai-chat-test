### 11 — تنظیمات Inference در UI
**وضعیت:** تصمیم ثبت شد

**پاسخ:**

تنظیمات Inference باید در دو سطح **Basic** و **Advanced** در UI ارائه شوند. UI باید فقط تنظیماتی را نمایش دهد که Runtime واقعاً پشتیبانی و اعمال می‌کند؛ نمایش تنظیمات صوری یا بدون اثر ممنوع است.

**Basic:**
- Temperature
- Max Tokens / Max New Tokens

**Advanced:**
- Top-K
- Top-P
- Min-P
- Repeat Penalty
- Seed
- Stop Sequences
- Context Length
- Structured Output / Grammar در صورت پشتیبانی واقعی Runtime

مقادیر اعمال‌شده باید با تنظیمات واقعی Runtime هماهنگ باشند و امکان مشاهده تنظیمات فعلی Inference نیز وجود داشته باشد.

**اصول تصمیم:**
- UI ساده برای تنظیمات پرکاربرد: الزامی
- بخش Advanced برای تنظیمات تخصصی: الزامی

- Temperature: نمایش داده شود
- Max Tokens / Max New Tokens: نمایش داده شود
- Top-K: نمایش داده شود
- Top-P: نمایش داده شود
- Min-P: نمایش داده شود

### 09 — Streaming پاسخ
**وضعیت:** تصمیم ثبت شد

**پاسخ:**

بله، **Streaming واقعی پاسخ الزامی است**.

پاسخ مدل باید هنگام Generation به‌صورت تدریجی از Runtime دریافت و در UI نمایش داده شود و نباید تا پایان Generation به‌صورت یک‌جا نمایش داده شود.

Streaming باید از Runtime تا UI به‌صورت واقعی پیاده‌سازی شود و امکان اندازه‌گیری **First Token Time** و **Generation Speed (tok/s)** را فراهم کند.

همچنین Streaming باید با قابلیت **Stop Generation** سازگار باشد تا Generation فعال بتواند در زمان تولید متوقف شود.

**الزامات تصمیم:**
- Streaming واقعی: الزامی
- نمایش تدریجی پاسخ: الزامی
- اندازه‌گیری First Token Time: الزامی
- اندازه‌گیری Generation Speed: الزامی
- سازگاری با Stop Generation: الزامی
- تشخیص پایان طبیعی Generation: الزامی
- مدیریت خطای واقعی هنگام Streaming: الزامی
- وابستگی به Mock/شبیه‌سازی: ممنوع

### 10 — Stop Generation
**وضعیت:** تصمیم ثبت شد

**پاسخ:**

بله، **Stop Generation الزامی است** و باید با Streaming واقعی یکپارچه باشد.

کاربر باید بتواند در زمان تولید پاسخ، Generation فعال را متوقف کند. توقف باید در سطح واقعی Runtime انجام شود و صرفاً متوقف‌کردن نمایش متن در UI نباشد؛ به‌طوری که پس از Stop، پردازش غیرضروری مدل نیز متوقف شود.

**رفتار پس از Stop:**

متن تولیدشده تا لحظه توقف باید **حفظ شود** و پاسخ با وضعیت مشخص **Stopped** علامت‌گذاری شود. متن ناقص نباید حذف شود و نباید به‌عنوان پاسخ کامل و طبیعی نمایش داده شود.

**الزامات تصمیم:**
- Stop Generation: الزامی
- توقف واقعی Generation در Runtime: الزامی
- سازگاری با Streaming: الزامی
- حفظ متن تولیدشده تا لحظه توقف: الزامی
- نمایش وضعیت Stopped: الزامی
- حذف متن ناقص پس از Stop: ممنوع
- وانمودکردن به پایان طبیعی پاسخ: ممنوع
