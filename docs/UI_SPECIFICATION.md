# مشخصات رابط کاربری

**وضعیت:** 🔒 UI v1 — تصمیم‌های طراحی ثبت و یکپارچه شده‌اند
**نسخه هدف:** ۱.۰.۰
**دامنه:** قرارداد و مستندسازی UI/UX؛ بدون پیاده‌سازی

> 🔴 **قانون اجباری: کل UI برنامه باید فارسی و راست‌چین (RTL) باشد.** این الزام برای تمام صفحه‌ها، Header، Sidebar، Menuها، Buttonها، Dialogها، وضعیت‌ها، خطاها، Empty Stateها و تمام متن‌های قابل مشاهده اعمال می‌شود. داده‌های ذاتاً فنی مانند نام مدل، کد، URL و شناسه فنی می‌توانند LTR باشند، اما ساختار و متن پیرامون آن‌ها فارسی و RTL باقی می‌ماند.

## خلاصه Contract

### Header

```text
[ گفت‌وگو │ کار │ ⋯ ]    ● آماده
                          مدل محلی       [ ☰ ]
```

- گروه چپ کمتر از نصف عرض Header است.
- گزینه فعال با خط ظریف زیر همان گزینه مشخص می‌شود.
- `⋯` شامل «لاگ» و «تنظیمات» است.
- Runtime/AI دوخطی است و ارتفاع آن با دکمه‌های Header برابر است.
- `☰` دکمه گرد Sidebar در سمت راست است.
- کنترل دائمی دیگری در Header وجود ندارد.

### Sidebar

Sidebar از سمت راست باز می‌شود و Overlay نیمه‌شفاف روی محتوای اصلی دارد.

```text
گفت‌وگوی جدید

ابزار
├── فضای کار
├── عیب‌یابی
└── تنظیمات

اطلاعات
└── درباره برنامه

اخیر
├── گفت‌وگوی فعلی
├── گفت‌وگوی ۱
├── گفت‌وگوی ۲
├── گفت‌وگوی ۳
├── گفت‌وگوی ۴
├── گفت‌وگوی ۵
└── مشاهده بیشتر
```

- Sidebar در موبایل، تبلت و صفحه بزرگ تطبیقی است.
- گفت‌وگوی فعلی Highlight ظریف + Indicator دارد.
- زمان گفتگو در سمت چپ، کوچک و خاکستری کم‌رنگ است.
- هر «مشاهده بیشتر» پنج گفت‌وگوی دیگر اضافه می‌کند.
- Long Press روی گفتگو منوی باز کردن / تغییر نام / حذف را از همان نقطه باز می‌کند.
- حذف قرمز است و Undo ده‌ثانیه‌ای با شمارشگر کوچک و `×` دارد.

### Chat

- پیام کاربر: حباب نیمه‌شفاف با رنگ روشن و آرام، با جهت بصری آبی روشن.
- پاسخ مدل: بدون حباب سنگین.
- Composer: Floating و Responsive.
- دکمه ارسال: گرد و تطبیقی.

### Composer

- موبایل: شناور و جمع‌وجور.
- تبلت: کمی بزرگ‌تر.
- دسکتاپ: محدود و مرکزگرا.
- Composer تا سقف ارتفاع مشخص رشد می‌کند و سپس متن داخلی Scroll می‌شود.
- موبایل: Enter خط جدید؛ ارسال فقط با دکمه.
- دسکتاپ: Enter خط جدید؛ Shift + Enter ارسال.

### Runtime

```text
● آماده
مدل محلی
```

وضعیت‌ها:

- آماده → ثابت
- در حال کار → Pulse ظریف
- در حال تولید → Pulse/تنفس ظریف
- خارج از دسترس → ثابت
- خطا → ثابت

هر وضعیت رنگ مخصوص خود را دارد، اما رنگ تنها روش انتقال معنا نیست.

## اصول غیرقابل نقض

۱. UI v1 قبل از پیاده‌سازی باید بر اساس همین Contract ساخته شود.
۲. تمام متن‌های UI فارسی و RTL هستند مگر داده ذاتاً فنی.
۳. هیچ Mock یا Placeholder جای وضعیت واقعی را نمی‌گیرد.
۴. UI نباید Core، تست‌ها، Performance یا Accessibility را تضعیف کند.
۵. افکت‌های بصری سنگین، Blur دائمی و Motion تزئینی ممنوع‌اند.
۶. تغییرات پس از قفل نیازمند اصلاح مستندات و نسخه‌بندی هستند.
۷. تغییر اندازه Header از C به B، در صورت نیاز آینده، یک تغییر کدی/Tokenی است و تنظیم کاربر نیست.
