# قرارداد وضعیت‌های رابط کاربری

**وضعیت:** 🔒 یکپارچه‌سازی‌شده برای UI v1

> 🔴 **تمام وضعیت‌ها و پیام‌های قابل مشاهده UI باید فارسی و راست‌چین (RTL) باشند.**

## ۱. وضعیت Runtime محلی

| وضعیت | رفتار UI |
|---|---|
| **آماده** | Runtime آماده دریافت کار است؛ نقطه ثابت است. |
| **در حال کار** | Runtime در حال پردازش است؛ نقطه Pulse ظریف دارد. |
| **در حال تولید** | مدل در حال تولید پاسخ است؛ نقطه تنفس/Pulse ظریف دارد. |
| **خارج از دسترس** | Runtime به دلیل مشکل عملکردی قابل استفاده نیست؛ نقطه ثابت است. |
| **خطا** | خطای Runtime یا برنامه رخ داده است؛ نقطه ثابت است. |

هر وضعیت رنگ مخصوص خود را دارد، اما رنگ فقط نشانه کمکی است و متن/semantics باید معنا را منتقل کند.

عبارت‌های «در حال اتصال» و «آفلاین» جایگزین وضعیت‌های کاربرمحور بالا نیستند.

## ۵. وضعیت گفت‌وگوی فعلی

گفت‌وگوی فعلی در بخش «اخیر» با دو نشانه مشخص می‌شود:

- Highlight بسیار ظریف روی Surface آیتم.
- Indicator کوچک فعال.

تشخیص وضعیت فعال نباید فقط به رنگ وابسته باشد.

## ۶. وضعیت Composer و ارسال

- Composer خالی → دکمه ارسال غیرفعال.
- متن وجود دارد → دکمه ارسال فعال.
- ارسال در حال انجام → دکمه در حالت Loading.
- پایان ارسال → بازگشت به حالت عادی.

## ۷. وضعیت حذف گفتگو

حذف گفتگو فوری است. پس از حذف:

- پیام «گفتگو حذف شد» نمایش داده می‌شود.
- Undo به مدت ۱۰ ثانیه فعال است.
- شمارشگر معکوس کوچک نمایش داده می‌شود.
- `×` پیام Undo را می‌بندد.
- پایان ۱۰ ثانیه → Undo منقضی می‌شود.

## ۸. زبان و دسترسی‌پذیری

تمام وضعیت‌های قابل مشاهده فارسی و RTL هستند. رنگ به‌تنهایی نباید معنا را منتقل کند و وضعیت‌های مهم باید برای فناوری‌های کمکی قابل تشخیص باشند.
