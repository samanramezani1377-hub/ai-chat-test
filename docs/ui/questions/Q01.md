# Q01 — جهت‌گیری کلی بصری

**وضعیت:** 🔒 تصمیم‌گیری شده

## سؤال

ظاهر کلی رابط کاربری پروژه باید چه رویکردی داشته باشد؟

## تصمیم

**پریمیومِ تمیز و گفت‌وگومحور**

UI باید مدرن، تمیز، آرام و حرفه‌ای باشد و تجربه را حول گفت‌وگو و محتوای کاربر متمرکز کند. ظاهر باید حس یک محصول نهایی و پریمیوم داشته باشد، اما بدون تزئینات سنگین یا افکت‌هایی که خوانایی، عملکرد یا دسترسی‌پذیری را کاهش دهند.

## اصول بصری

- گفت‌وگو در مرکز تجربه
- کمینه‌سازی شلوغی بصری
- ایجاد سلسله‌مراتب با تایپوگرافی، فاصله‌گذاری و سطوح
- کامپوننت‌های گرد اما کنترل‌شده
- جداسازی نرم سطوح به‌جای Shadowهای سنگین
- عمق بصری ظریف به‌جای افکت تزئینی
- حفظ یکسانی سلسله‌مراتب اطلاعات در تم روشن و تاریک
- استفاده از حرکت فقط برای توضیح وضعیت یا تعامل
- جداسازی اطلاعات فنی از گفت‌وگوی عادی
- عدم وابستگی وضعیت‌ها به رنگ به‌تنهایی

## زبان سطوح

Surfaceها باید ساده و نرم باشند. استفاده محدود از شفافیت، Blur یا عمق بصری در صورت نیاز مجاز است، اما نباید هویت اصلی UI شوند یا باعث افت محسوس عملکرد شوند.

## این جهت‌گیری چه چیزی نیست؟

- Glassmorphism افراطی نیست.
- Material 3 خام و بدون شخصی‌سازی نیست.
- Neon یا Cyberpunk نیست.
- رابط شلوغ و پر از Card و Shadow نیست.
- کپی مستقیم از محصول دیگری نیست.

۶. پرداخت بصری پریمیوم

## پیامدها

این تصمیم باید در `DESIGN_SYSTEM.md`، App Shell، گفت‌وگو، فضای کار، کامپوننت‌ها، حرکت و تم‌ها اعمال شود.

این تصمیم یک زبان طراحی داخلی برای پروژه تعریف می‌کند و وابسته به برند یا محصول خارجی نیست.
