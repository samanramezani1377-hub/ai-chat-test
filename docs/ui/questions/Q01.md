# Q01 — Overall Visual Direction

**Status:** 🔒 Decided

## Question

ظاهر کلی UI پروژه باید چه رویکردی داشته باشد؟

## Decision

**Clean Conversational Premium**

UI باید مدرن، تمیز، آرام و حرفه‌ای باشد و تجربه را حول گفتگو و محتوای کاربر متمرکز کند. ظاهر باید حس محصول نهایی و Premium داشته باشد، اما بدون تزئینات سنگین یا افکت‌هایی که خوانایی، Performance یا Accessibility را کاهش دهند.

## Visual Principles

- Conversation-first
- Minimal visual noise
- Hierarchy through typography, spacing and surfaces
- Rounded but restrained components
- Soft surface separation instead of heavy shadows
- Subtle depth rather than decorative effects
- Light and dark themes with the same information hierarchy
- Motion only when it communicates state or interaction
- Technical information visually separated from normal conversation
- No dependence on color alone for status

## Surface Language

Surfaceها باید ساده و نرم باشند. استفاده محدود از transparency، blur یا depth در صورت نیاز مجاز است، اما این موارد نباید هویت اصلی UI شوند یا باعث افت محسوس Performance شوند.

## What This Direction Is Not

- Glassmorphism افراطی نیست.
- Material 3 خام و بدون شخصی‌سازی نیست.
- Neon یا Cyberpunk نیست.
- رابط شلوغ و پر از Card و Shadow نیست.
- کپی مستقیم از محصول دیگری نیست.

## UX Priority Order

1. خوانایی
2. کاربردپذیری
3. Accessibility
4. Performance
5. Visual hierarchy
6. Premium visual polish

## Consequences

این تصمیم باید در `DESIGN_SYSTEM.md`، App Shell، Chat، Workspace، Components، Motion و Themeها اعمال شود.

این تصمیم مستقل از هر برند یا محصول خارجی است و صرفاً یک زبان طراحی داخلی برای پروژه تعریف می‌کند.
