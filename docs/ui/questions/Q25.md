# سؤال ۲۵ — دسترسی به اطلاعات مدل و Inference

**وضعیت:** ⏳ در انتظار پاسخ

اطلاعات مدل فعال و تنظیمات Inference از کجا و با چه سطحی در دسترس باشند؟

### A — فقط در Runtime Header
نام مدل در Header کافی باشد و جزئیات دیگری نمایش داده نشود.

### B — با لمس Runtime ⭐
با لمس بخش Runtime در Header، پنل جزئیات مدل باز شود؛ شامل مدل فعال و وضعیت Loaded/Loading/Unloaded/Error و اطلاعات اصلی Inference.

### C — داخل تنظیمات
اطلاعات مدل و Inference فقط در بخش تنظیمات قابل مشاهده باشند.

### D — داخل فضای کار
جزئیات مدل برای اجرای فعلی در فضای کار نمایش داده شوند.

### E — ترکیبی
خلاصه در Header و جزئیات کامل در تنظیمات/فضای کار، بدون تکرار غیرضروری اطلاعات.
