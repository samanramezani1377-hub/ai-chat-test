# سؤال ۳۸ — جایگاه مرکز خطاها

**وضعیت:** ⏳ در انتظار پاسخ

مرکز مستقل خطاها و گزارش خطا در UI چه جایگاهی داشته باشد؟

### A — ادغام با عیب‌یابی ⭐
«عیب‌یابی» هم Trace و ابزارهای فنی را پوشش دهد و هم مرکز خطاها/گزارش خطا باشد.

### B — مقصد مستقل
در Sidebar یک مقصد مستقل «خطاها» اضافه شود.

### C — داخل تنظیمات
گزارش خطاها در بخش تنظیمات و زیرمجموعه عیب‌یابی قرار بگیرد.

### D — فقط Contextual
خطاها فقط کنار همان گفتگو/Action نمایش داده شوند و مرکز خطای مستقل نداشته باشند.

### E — ترکیبی
خلاصه خطا در Context مربوط به خودش نمایش داده شود و فهرست کامل خطاها در عیب‌یابی قابل دسترسی باشد.
