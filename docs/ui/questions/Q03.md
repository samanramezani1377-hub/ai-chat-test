# سؤال ۳ — ظاهر بصری هدر

**وضعیت:** 🔒 تصمیم‌گیری شد

## سؤال
ظاهر خود هدر چگونه باشد؟

## تصمیم
**گزینه D — ترکیبی**

هدر باید یک سطح نرم و کمی برجسته باشد؛ تمیز، مدرن و Premium، بدون افکت‌های سنگین.

### ویژگی‌ها
- Surface مستقل و نرم.
- گوشه‌های ظریف و هماهنگ با Design System.
- سایه بسیار کم و کنترل‌شده.
- بدون Blur دائمی.
- در صورت نیاز، شفافیت بسیار محدود و سبک مجاز است.
- هدر نباید از محتوای اصلی گفتگو توجه بیشتری بگیرد.
- خوانایی و Performance بر افکت‌های بصری اولویت دارند.

### موارد ممنوع
- Glass افراطی.
- سایه‌های سنگین.
- Blur سنگین یا دائمی.
- گرادیان‌های تزئینی سنگین.
- افکت‌های نئونی.
- انیمیشن تزئینی.

### ارتباط با زبان کلی UI
این تصمیم ادامه مستقیم تصمیم Q01 یعنی **Clean Conversational Premium** است و باید در Light/Dark Theme و Design System یکسان و منسجم اجرا شود.

### الزام زبان
تمام متن‌های قابل مشاهده در هدر باید **فارسی و راست‌چین (RTL)** باشند. نام‌های فنی، کد، URL و شناسه‌ها فقط در محل‌های فنی مربوط به خود و با قواعد RTL/LTR مناسب نمایش داده می‌شوند.
