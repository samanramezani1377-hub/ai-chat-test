# سؤال ۵ — شکل دکمه‌های هدر

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم

**گزینه C — ترکیبی**

گروه سمت چپ شامل `Chat`، `Work` و `⋯` در یک Container کپسولی مشترک قرار می‌گیرد و دکمه همبرگری سمت راست یک دکمه گرد مستقل است.

```text
┌────────────────────┐              ╭────╮
│ Chat │ Work │  ⋯   │              │ ☰  │
└────────────────────┘              ╰────╯
```

## وضعیت فعال

صفحه فعال با **یک خط ظریف در زیر همان گزینه** مشخص می‌شود.

```text
┌────────────────────┐
│ Chat │ Work │  ⋯   │
│ ────               │
└────────────────────┘
```

اگر Work فعال باشد:

```text
┌────────────────────┐
│ Chat │ Work │  ⋯   │
│        ────        │
└────────────────────┘
```

Indicator باید ظریف، واضح و بدون تغییر شدید رنگ یا اندازه باشد.

## رفتار کنترل‌ها

- `Chat` مقصد اصلی گفت‌وگو است.
- `Work` مقصد Workspace است.
- `⋯` منوی ابزارها و تنظیمات جانبی است.
- `☰` منوی اصلی Sidebar را باز می‌کند.

## زبان و راست‌چین

تمام متن‌های قابل مشاهده باید **فارسی و راست‌چین (RTL)** باشند. نام‌های کوتاه کنترل‌ها نیز باید تا حد امکان معادل فارسی داشته باشند و در Design System نهایی شوند.

## Accessibility

- وضعیت فعال نباید فقط با خط یا رنگ قابل تشخیص باشد؛ کنترل فعال باید وضعیت معنایی قابل دسترس داشته باشد.
- همه کنترل‌ها باید نام دسترسی مناسب داشته باشند.
- اندازه ناحیه لمسی باید برای استفاده راحت در موبایل کافی باشد.
