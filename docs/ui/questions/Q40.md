# سؤال ۴۰ — کنترل Visibility معیارهای Performance

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم نهایی

**گزینه D — فهرست + گروه‌بندی**

کنترل نمایش معیارهای عملکرد در مسیر **تنظیمات → عملکرد** قرار می‌گیرد.

گروه‌های معیارها قابل باز و بسته‌شدن هستند و داخل هر گروه، هر Metric یک کنترل Visibility مستقل دارد.

```text
تنظیمات
└── عملکرد
    ├── ▼ مدل
    │   ├── زمان پردازش       👁 نمایش
    │   └── ...
    ├── ▶ استنتاج
    ├── ▶ دستگاه
    ├── ▶ عامل
    └── ▶ شبکه
```

### اصل مهم

Visibility فقط مشخص می‌کند Metric در UI نمایش داده شود یا مخفی بماند؛ **اندازه‌گیری واقعی Metric متوقف نمی‌شود**.

همچنین اگر یک Metric در Runtime/دستگاه قابل اندازه‌گیری نباشد، نباید مقدار ساختگی یا Mock نمایش داده شود.

## زبان و راست‌چین

تمام متن‌ها و اجزای این مسیر باید فارسی و راست‌چین (RTL) باشند.

## قفل UI

این تصمیم بخشی از UI Contract است و قبل از کدنویسی نهایی قفل شده است.
