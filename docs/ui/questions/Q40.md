# سؤال ۴۰ — کنترل Visibility معیارهای Performance

**وضعیت:** ⏳ در انتظار پاسخ

برای Metricهای Performance که هرکدام باید Visibility مستقل داشته باشند، UI چه مدلی داشته باشد؟

### A — فقط تنظیم کلی
یک گزینه کلی برای نمایش/عدم نمایش Performance وجود داشته باشد و Metricها جدا نشوند.

### B — فهرست مستقل Metricها ⭐
هر Metric یک ردیف مستقل با کنترل نمایش/مخفی‌سازی خودش داشته باشد؛ بدون تأثیر بر Measurement واقعی.

### C — گروه‌بندی Metricها
Metricها در گروه‌های Inference، Model، Device، Agent و Network قرار بگیرند و هر گروه کنترل Visibility داشته باشد.

### D — فهرست + گروه‌بندی
گروه‌ها قابل باز و بسته‌شدن باشند و داخل هر گروه، هر Metric کنترل Visibility مستقل داشته باشد.

### E — تطبیقی
نمایش Metricها بر اساس قابلیت واقعی Runtime/دستگاه محدود شود؛ Metric غیرقابل‌اندازه‌گیری به‌صورت «در دسترس نیست» نمایش داده شود یا طبق Visibility پنهان بماند، بدون Mock و بدون توقف Measurement سایر Metricها.
