# سؤال ۳۲ — کنترل‌های Workspace

**وضعیت:** ⏳ در انتظار پاسخ

برای Preview و نتیجه Action در «فضای کار»، کدام کنترل‌ها در UI قرار بگیرند؟

### A — فقط مشاهده
Preview و Result فقط خواندنی باشند.

### B — تأیید/رد
کنترل‌های «تأیید»، «رد» و «لغو» در کنار نتیجه قرار بگیرند.

### C — ویرایش
علاوه بر تأیید/رد، امکان «ویرایش» داده قبل از تأیید وجود داشته باشد.

### D — کنترل تطبیقی ⭐
فقط Actionهایی که واقعاً به آن کنترل نیاز دارند، کنترل مناسب خودشان را نشان دهند؛ مثلاً Preview → تأیید/رد، داده قابل اصلاح → ویرایش، اجرای قابل لغو → لغو.

### E — کامل
همه کنترل‌ها شامل تأیید، رد، ویرایش، لغو و Confirm در یک نوار ثابت نمایش داده شوند.
