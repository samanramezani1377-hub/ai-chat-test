# سؤال ۲۴ — تاریخچه و خروجی عملکرد

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم نهایی

**گزینه E — کامل**

تاریخچه عملکرد باید در Workspace قابل مشاهده باشد و امکانات **مقایسه اجراها، خروجی گرفتن گزارش و فیلتر و مشاهده جزئیات هر اجرا** نیز فراهم شود.

```text
فضای کار
└── عملکرد
    ├── اجرای فعلی
    ├── تاریخچه اجراها
    │   ├── فیلتر
    │   ├── انتخاب چند اجرا
    │   ├── مقایسه
    │   └── مشاهده جزئیات
    └── خروجی گزارش
```

همچنین سوابق عملکردی در بخش مربوط به Performance در **عیب‌یابی** نگهداری می‌شوند.

## اصل طراحی

- تاریخچه فقط یک فهرست خام نیست؛ هر اجرا باید جزئیات قابل مشاهده داشته باشد.
- مقایسه باید امکان بررسی چند اجرای قبلی را فراهم کند.
- Export باید گزارش عملکرد را بدون ساخت داده جعلی یا ناقص تولید کند.
- فیلترها برای محدودکردن تاریخچه اجراها در نظر گرفته می‌شوند.
- نمایش Workspace برای بررسی عملیاتی و عیب‌یابی برای تحلیل عمیق‌تر استفاده می‌شود.

## زبان و راست‌چین

تمام متن‌ها و اجزای این مسیر باید فارسی و راست‌چین (RTL) باشند.
