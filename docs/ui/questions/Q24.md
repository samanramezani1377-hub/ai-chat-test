# سؤال ۲۴ — تاریخچه و خروجی عملکرد

**وضعیت:** ⏳ در انتظار پاسخ

برای Performance History و Export گزارش عملکرد چه تجربه‌ای می‌خواهیم؟

### A — فقط تاریخچه
تاریخچه Metricها قابل مشاهده باشد ولی Export نداشته باشد.

### B — تاریخچه + خروجی ⭐
تاریخچه عملکرد قابل مشاهده باشد و کاربر بتواند گزارش را Export کند.

### C — فقط گزارش اجرای فعلی
فقط Metricهای اجرای فعلی نمایش داده شوند و تاریخچه حذف شود.

### D — مقایسه اجراها
کاربر بتواند چند اجرای قبلی را انتخاب و Metricهای آن‌ها را مقایسه کند.

### E — کامل
تاریخچه + مقایسه + Export، با فیلتر و جزئیات هر اجرا.
