# سؤال ۳۶ — مسیر رابط کاربری Actionها

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم نهایی

**گزینه D — هر دو**

Actionها در دو سطح UI نمایش داده می‌شوند:

### ۱. کاتالوگ Actionها در بخش ابزارها

فهرست کلی Actionهای قابل استفاده در پروژه در بخش «ابزارها» قرار می‌گیرد و می‌تواند بر اساس دسته‌بندی سازمان‌دهی شود.

### ۲. خلاصه Action در صفحه گفت‌وگو

وقتی یک Action واقعاً در پاسخ به درخواست کاربر اجرا می‌شود، خلاصه اجرای آن در همان گفت‌وگو نمایش داده می‌شود؛ برای نمونه:

- ● در حال انجام
- ✓ انجام شد
- ⚠ نیازمند تأیید
- ✕ خطا

این نمایش باید خلاصه و هماهنگ با UI گفتگو باشد و جای پاسخ اصلی را نگیرد.

### ۳. جزئیات کامل در فضای کار

با انتخاب خلاصه Action از صفحه گفت‌وگو، کاربر می‌تواند وارد «فضای کار» شود و جزئیات کامل اجرای همان Action را مشاهده کند؛ از جمله مراحل اجرا، نتیجه ابزار، Preview، Verification، Trace و Recovery در صورت وجود.

## اصل تفکیک

```text
ابزارها
└── Actionها
    └── چه قابلیت‌هایی در دسترس هستند؟

گفت‌وگو
└── خلاصه Action
    └── چه اتفاقی برای درخواست فعلی افتاد؟

فضای کار
└── اجرای Action
    └── دقیقاً چگونه اجرا شد؟
```

## زبان و راست‌چین

کل این مسیر UI باید فارسی و راست‌چین (RTL) باشد.
