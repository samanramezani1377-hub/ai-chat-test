# سؤال ۳۶ — مسیر رابط کاربری Actionها

**وضعیت:** ⏳ در انتظار پاسخ

Action Registry و Actionهای قابل اجرا در پروژه از نظر UI چه جایگاهی داشته باشند؟

### A — بدون صفحه مستقل
Actionها فقط توسط سیستم و فضای کار استفاده شوند و کاربر فهرست مستقلی از آن‌ها نبیند.

### B — داخل فضای کار ⭐
Actionهای مربوط به اجرای فعلی در «فضای کار» نمایش داده شوند و جزئیات هر Action قابل مشاهده باشد.

### C — داخل ابزارها
در بخش «ابزار» یک فهرست Actionها و دسته‌بندی آن‌ها نمایش داده شود.

### D — هر دو
فهرست کلی Actionها در ابزارها و Actionهای اجرای فعلی در فضای کار نمایش داده شوند.

### E — تطبیقی
در v1 فقط Actionهای مرتبط با اجرای فعلی نمایش داده شوند، اما معماری UI برای اضافه‌شدن Catalog مستقل در آینده آماده باشد.
