# سؤال ۱۹ — دکمه ارسال

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم

**گزینه D — دکمه ارسال تطبیقی**

دکمه ارسال متناسب با اندازه صفحه تغییر اندازه می‌دهد، اما ساختار و هویت بصری آن ثابت می‌ماند.

### موبایل

- دکمه گرد و کوچک داخل Composer.
- مناسب تعامل لمسی.

### تبلت

- دکمه کمی بزرگ‌تر.
- همچنان گرد و مینیمال.

### دسکتاپ

- دکمه گرد با اندازه متوسط.
- هماهنگ با Composer شناور.

## وضعیت دکمه

- Composer خالی → دکمه غیرفعال.
- متن وجود دارد → دکمه فعال.
- هنگام ارسال → حالت Loading.
- پس از پایان ارسال → بازگشت به وضعیت عادی.

## زبان بصری

- دکمه باید با Surface Premium Composer هماهنگ باشد.
- تغییر اندازه نباید Layout را مختل کند.
- Motion و Loading باید کوتاه و مینیمال باشند.
- دکمه نباید از محتوای گفتگو توجه بیشتری بگیرد.

## زبان و راست‌چین

تمام متن‌های قابل مشاهده فارسی و راست‌چین (RTL) هستند.

## Accessibility

- وضعیت فعال/غیرفعال باید از نظر معنایی قابل تشخیص باشد.
- Loading باید برای فناوری‌های کمکی اعلام شود.
- دکمه باید نام دسترسی مناسب برای «ارسال» داشته باشد.
