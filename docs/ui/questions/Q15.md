# سؤال ۱۵ — وضعیت Runtime / AI در Header

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم

**گزینه B — وضعیت + نام Runtime**

بخش Runtime/AI بین گروه کنترل‌های `چت / کار / ⋯` و دکمه گرد Sidebar قرار می‌گیرد.

نمایش دوخطی است:

```text
● آماده
مدل محلی
```

> پرانتزهای استفاده‌شده در توضیح سؤال صرفاً برای خوانایی هستند و نباید در UI نمایش داده شوند.

## اندازه و تراز

ارتفاع کل این بخش دوخطی باید با ارتفاع دکمه‌های Header **برابر و هم‌تراز** باشد.

- دو خط در یک Container با ارتفاع کنترل‌شده قرار می‌گیرند.
- بخش Runtime نباید ارتفاع Header را افزایش دهد.
- دکمه‌های `چت / کار / ⋯` و `☰` از نظر ارتفاع کلی با بخش Runtime هم‌سطح هستند.
- متن دوخطی باید از نظر عمودی در مرکز Header قرار بگیرد.
- فاصله بین نقطه وضعیت، متن وضعیت و نام Runtime باید کم و منظم باشد.
- نام Runtime نسبت به وضعیت اصلی وزن بصری کمتری دارد.

## وضعیت‌ها

مقادیر معنایی فعلی:

- `آماده`
- `در حال کار`
- `در حال تولید`
- `خارج از دسترس`
- `خطا`

Indicator وضعیت با نقطه کوچک نمایش داده می‌شود و وضعیت نباید فقط با رنگ قابل تشخیص باشد.

## سبک بصری

- مینیمال و خوانا.
- بدون Badge بزرگ.
- بدون Container سنگین.
- نقطه وضعیت کوچک.
- نام Runtime ظریف‌تر از وضعیت اصلی.
- هماهنگ با Header Premium و Design System.

## زبان و راست‌چین

تمام متن‌های قابل مشاهده باید **فارسی و راست‌چین (RTL)** باشند.

## آمادگی پیاده‌سازی

ارتفاع این بخش باید مستقل و Token محور تعریف شود تا در صورت تغییر اندازه Header از گزینه C به B، این بخش بدون تغییر معماری همچنان با ارتفاع دکمه‌ها هم‌تراز باقی بماند.
