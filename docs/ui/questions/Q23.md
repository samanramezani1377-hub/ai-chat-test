# سؤال ۲۳ — محل نمایش عملکرد Runtime

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم نهایی

**گزینه D — داخل فضای کار**

Metricهای مربوط به اجرای فعلی در **«فضای کار»** نمایش داده می‌شوند و تاریخچه عملکرد نیز در همان مسیر قابل دسترسی خواهد بود.

```text
فضای کار
├── اجرای فعلی
│   └── Metricهای عملکرد Runtime / Inference
└── تاریخچه عملکرد
```

### اصل طراحی

اطلاعات عملکرد Runtime نباید فضای Header یا گفت‌وگوی اصلی را شلوغ کند. Workspace محل اصلی مشاهده و بررسی عملکرد اجرای فعلی است.

## زبان و راست‌چین

تمام متن‌ها و اجزای این مسیر باید فارسی و راست‌چین (RTL) باشند.
