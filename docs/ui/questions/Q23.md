# سؤال ۲۳ — محل نمایش عملکرد Runtime

**وضعیت:** ⏳ در انتظار پاسخ

اطلاعات عملکردی Runtime و Inference در کجا در UI قرار بگیرد؟

### A — داخل عیب‌یابی
تمام Metricها فقط در بخش «عیب‌یابی» نمایش داده شوند.

### B — داخل تنظیمات
یک بخش «عملکرد» زیر تنظیمات قرار بگیرد.

### C — صفحه مستقل عملکرد ⭐
یک مقصد مستقل «عملکرد» در ساختار برنامه داشته باشیم.

### D — داخل فضای کار
Metricهای مربوط به اجرای فعلی در «فضای کار» نمایش داده شوند و تاریخچه جداگانه داشته باشند.

### E — ترکیبی
خلاصه عملکرد اجرای فعلی در فضای کار/عیب‌یابی و تاریخچه کامل در یک مقصد مستقل نمایش داده شود.
