# سؤال ۲۹ — Recovery و Retry

**وضعیت:** ⏳ در انتظار پاسخ

وقتی یک Action قابل بازیابی یا Retry است، این قابلیت در UI چگونه نمایش داده شود؟

### A — فقط عیب‌یابی
Recovery و Retry فقط در بخش عیب‌یابی قابل دسترسی باشند.

### B — کنار همان Action ⭐
کنترل Retry/بازیابی مستقیماً کنار Action ناموفق یا قابل بازیابی نمایش داده شود.

### C — Dialog تأیید
قبل از هر Retry یک Dialog کوچک برای تأیید کاربر باز شود.

### D — خودکار
اگر Recovery ایمن باشد، سیستم خودکار Retry کند و فقط نتیجه را به کاربر نشان دهد.

### E — هوشمند
برای Retry ایمن، کنترل مستقیم؛ برای موارد حساس، تأیید کاربر؛ و برای موارد نیازمند مداخله، انتقال واضح به عیب‌یابی.
