# سؤال ۲۶ — کنترل‌های Inference

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم نهایی

**گزینه B — داخل تنظیمات**

کنترل‌های واقعی Inference در بخش **تنظیمات** قرار می‌گیرند و تغییرات کاربر باید واقعاً روی Runtime اعمال شوند.

کنترل‌ها فقط برای قابلیت‌هایی ارائه می‌شوند که Core واقعاً پشتیبانی می‌کند؛ UI نباید کنترل صوری، Mock یا تنظیماتی که Runtime آن را اعمال نمی‌کند نمایش دهد.

```text
تنظیمات
└── Inference
    ├── Temperature
    ├── Max New Tokens
    ├── Top K
    ├── Top P
    ├── Min P
    ├── Repeat Penalty
    ├── Seed
    ├── Stop Sequences
    └── Context Length
```

### اصل طراحی

- تغییر هر مقدار باید به تنظیم واقعی اجرای Inference متصل باشد.
- تنظیمات دائمی از کنترل‌های لحظه‌ای اجرای فعلی جدا هستند.
- توقف/ادامه تولید طبق Q21 و Q22 در کنترل تولید پاسخ مدیریت می‌شود و در این بخش تکرار نمی‌شود.
- اگر قابلیتی در Core وجود نداشته باشد، نباید برای آن کنترل UI ساخته شود.

## زبان و راست‌چین

تمام متن‌ها و اجزای این مسیر باید فارسی و راست‌چین (RTL) باشند.
