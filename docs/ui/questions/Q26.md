# سؤال ۲۶ — کنترل‌های Inference

**وضعیت:** ⏳ در انتظار پاسخ

تنظیمات قابل مشاهده/قابل کنترل Inference چگونه در UI ارائه شوند؟

### A — فقط نمایش
تنظیمات فعلی فقط نمایش داده شوند و از UI تغییر نکنند.

### B — داخل تنظیمات ⭐
کنترل‌های Inference در بخش تنظیمات قرار بگیرند و تغییرات واقعی روی Runtime اعمال شوند.

### C — داخل Runtime Panel
با بازکردن جزئیات Runtime، تنظیمات قابل تغییر نیز همان‌جا قرار بگیرند.

### D — تنظیمات سریع
فقط چند کنترل اصلی به‌صورت Quick Controls کنار Runtime در دسترس باشند و تنظیمات کامل در تنظیمات قرار بگیرند.

### E — بدون کنترل در v1
در نسخه فعلی فقط وضعیت و اطلاعات مدل نمایش داده شود و کنترل‌های Inference به مرحله بعد موکول شوند.
