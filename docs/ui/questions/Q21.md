# سؤال ۲۱ — توقف تولید پاسخ

**وضعیت:** ⏳ در انتظار پاسخ

وقتی Runtime در وضعیت «در حال تولید» است، دکمه ارسال Composer چه رفتاری داشته باشد؟

### A — تبدیل به توقف
دکمه ارسال به دکمه «توقف» تبدیل شود و با زدن آن تولید همان لحظه متوقف شود.

### B — دکمه توقف جداگانه
دکمه ارسال همچنان باقی بماند و یک دکمه توقف جداگانه کنار آن نمایش داده شود.

### C — فقط از بخش وضعیت Runtime
توقف تولید از بخش وضعیت Runtime در Header انجام شود.

### D — توقف داخل پیام در حال تولید
یک کنترل توقف کوچک کنار/زیر پاسخ در حال تولید نمایش داده شود.

### E — ترکیبی
روی موبایل، توقف داخل Composer باشد و روی دسکتاپ کنترل توقف جداگانه در کنار Composer قرار بگیرد.
