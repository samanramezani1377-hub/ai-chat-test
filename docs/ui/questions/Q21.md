# سؤال ۲۱ — توقف تولید پاسخ

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم نهایی

**گزینه A — تبدیل دکمه ارسال به توقف**

وقتی Runtime در وضعیت «در حال تولید» است، دکمه ارسال Composer به دکمه **«توقف»** تبدیل می‌شود. با انتخاب آن، تولید همان لحظه متوقف می‌شود.

## رفتار UI

```text
حالت عادی
[ Composer                         ] [ ارسال ]

در حال تولید
[ Composer                         ] [ توقف ]
```

دکمه توقف همان جایگاه دکمه ارسال را می‌گیرد تا کاربر برای توقف تولید مجبور به پیدا کردن کنترل جدید در بخش دیگری از UI نباشد.

## زبان و راست‌چین

تمام متن‌ها و اجزای این مسیر باید فارسی و راست‌چین (RTL) باشند.

## قفل UI

این تصمیم بخشی از UI Contract است و قبل از کدنویسی نهایی قفل شده است.
