# سؤال ۱۷ — نمایش پیام‌ها

## تصمیم

**گزینه C — ترکیبی Premium**

پیام کاربر به‌صورت یک حباب مستقل و پاسخ مدل بدون حباب نمایش داده می‌شود.

```text
                 ╭──────────────────────╮
                 │ پیام کاربر           │
                 ╰──────────────────────╯

```

## حباب پیام کاربر

حباب پیام کاربر باید:

- نیمه‌شفاف باشد.
- دارای رنگ روشن و آرام باشد؛ نمونه پیشنهادی: **آبی روشن**.
- مینیمال و Premium باشد.
- از رنگ بسیار اشباع یا تند استفاده نکند.
- Radius و فاصله داخلی با Design System هماهنگ باشد.
- اندازه حباب بر اساس طول محتوا باشد و بی‌دلیل عرض کامل صفحه را اشغال نکند.

رنگ آبی روشن نمونه است و مقدار نهایی آن در Design System تعیین می‌شود.

## پاسخ مدل

پاسخ مدل بدون حباب مجزا نمایش داده می‌شود تا متن اصلی خواناتر و سبک‌تر باشد.

- Typography عنصر اصلی است.
- فاصله مناسب بین پیام‌ها ایجاد می‌شود.
- پاسخ نباید داخل Card/Surface سنگین قرار گیرد.
- عناصر کنترلی پاسخ در صورت نیاز باید مینیمال باشند.

## زبان و راست‌چین

تمام متن‌های قابل مشاهده باید **فارسی و راست‌چین (RTL)** باشند.

## Accessibility

رنگ حباب پیام کاربر نباید تنها راه تشخیص فرستنده باشد؛ ساختار، جایگاه و معنای معنایی پیام نیز باید این تفاوت را منتقل کند.
