# سؤال ۱۴ — وضعیت فعال گفت‌وگوی فعلی

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم

**گزینه D — Highlight ظریف + Indicator**

گفت‌وگوی فعلی در بخش «اخیر» با ترکیب یک Surface بسیار ظریف و یک Indicator کوچک از سایر گفتگوها متمایز می‌شود.

```text
اخیر

╭──────────────────────────────────╮
│ ●  گفت‌وگوی فعلی          همین الان│
╰──────────────────────────────────╯

○  گفت‌وگوی ۱              ۵ دقیقه پیش
○  گفت‌وگوی ۲              ۱ ساعت پیش
```

## Highlight

- فقط پشت گفت‌وگوی فعلی یک Surface بسیار ظریف قرار می‌گیرد.
- رنگ آن خنثی و هماهنگ با Surfaceهای UI است.
- نباید تند یا شبیه هشدار باشد.
- Radius با Design System مشترک است.
- هدف فقط مشخص‌کردن موقعیت فعلی کاربر است.

## Indicator

- یک Indicator کوچک برای گفت‌وگوی فعال نمایش داده می‌شود.
- گفتگوهای غیرفعال Indicator خنثی دارند.
- وضعیت فعال نباید فقط با رنگ منتقل شود.
- Indicator باید ساده و کم‌حجم باشد.

## هماهنگی با Header

در Header، گزینه فعال با خط ظریف زیر آن مشخص می‌شود؛ در Sidebar همین مفهوم با Highlight ظریف + Indicator اجرا می‌شود تا زبان بصری فعال/غیرفعال در کل برنامه یکپارچه باشد.

## زبان و راست‌چین

تمام متن‌های قابل مشاهده باید **فارسی و راست‌چین (RTL)** باشند.

## Accessibility

- گفت‌وگوی فعلی باید از نظر معنایی به‌عنوان مورد فعال مشخص شود.
- تشخیص وضعیت فعال نباید فقط به رنگ یا ظاهر وابسته باشد.
