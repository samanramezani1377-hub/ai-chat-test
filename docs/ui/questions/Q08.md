# سؤال ۸ — ظاهر Sidebar

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم

**گزینه E — ترکیبی**

Sidebar بر پایه یک **Surface Premium** طراحی می‌شود، اما میزان شناوری آن متناسب با اندازه صفحه تغییر می‌کند.

### موبایل

- Sidebar نزدیک‌تر به لبه صفحه قرار می‌گیرد.
- Surface همچنان نرم و مستقل است.
- فاصله از لبه‌ها حداقلی و متناسب با فضای محدود موبایل است.

### تبلت

- Sidebar کمی شناورتر می‌شود.
- فاصله ظریف از لبه‌ها ایجاد می‌شود.
- Shadow همچنان کنترل‌شده باقی می‌ماند.

### صفحه بزرگ

- Sidebar کاملاً Floating است.
- فاصله بیشتری از لبه صفحه دارد.
- گوشه‌های نرم‌تر و Shadow کمی محسوس‌تر دارد.
- نباید حس یک پنل سنگین یا مزاحم ایجاد کند.

## زبان بصری

Sidebar باید با Header و زبان **Clean Conversational Premium** هماهنگ باشد.

- Surface نرم
- عمق بصری کنترل‌شده
- Shadow تطبیقی
- بدون Glass افراطی
- بدون Blur سنگین
- بدون تزئینات غیرضروری

## Overlay

هنگام باز بودن Sidebar، یک **لایه نیمه‌شفاف** بین Sidebar و محتوای اصلی قرار می‌گیرد تا تمرکز روی Sidebar ایجاد شود، در حالی که محتوای اصلی همچنان در پس‌زمینه قابل تشخیص باشد.

این Overlay بخشی از رفتار Q07 است و نباید حذف شود.

## زبان و راست‌چین

تمام متن‌های قابل مشاهده Sidebar باید **فارسی و راست‌چین (RTL)** باشند.

## آمادگی پیاده‌سازی

فاصله، Radius، Shadow و اندازه Surface باید از Tokenها/Breakpointهای Design System پیروی کنند تا رفتار تطبیقی بدون بازطراحی Component قابل تغییر باشد.
