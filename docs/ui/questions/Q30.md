# سؤال ۳۰ — Verification و مداخله کاربر

**وضعیت:** ⏳ در انتظار پاسخ

برای Actionهایی که نیاز به Verification یا مداخله کاربر دارند، UI چگونه رفتار کند؟

### A — نمایش وضعیت
فقط وضعیت «نیازمند تأیید» یا «نیازمند مداخله» نمایش داده شود.

### B — تأیید در همان Context ⭐
کنترل تأیید/رد مستقیماً در همان Context اجرای Action نمایش داده شود.

### C — انتقال به عیب‌یابی
کاربر برای تأیید یا مداخله به بخش عیب‌یابی منتقل شود.

### D — Dialog
برای هر Verification یک Dialog مستقل باز شود.

### E — هوشمند و Contextual
Verification در همان Context و با حداقل جابه‌جایی انجام شود؛ موارد حساس Dialog یا تأیید صریح داشته باشند و موارد نیازمند مداخله مسیر واضحی به عیب‌یابی ارائه کنند.
