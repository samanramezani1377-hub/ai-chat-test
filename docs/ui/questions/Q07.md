# سؤال ۷ — رفتار Sidebar و ساختار محتوای آن

**وضعیت:** 🔒 تصمیم‌گیری شده

## تصمیم

با لمس دکمه گرد همبرگری در سمت راست هدر، Sidebar اصلی از **سمت راست** باز می‌شود و با اندازه صفحه تطبیق پیدا می‌کند.

## رفتار واکنش‌گرا

### موبایل

Sidebar به‌صورت Overlay باز می‌شود و بخش عمده صفحه را در اختیار می‌گیرد؛ محتوای اصلی در پشت آن باقی می‌ماند.

### تبلت

Sidebar همچنان Overlay است، اما عرض آن متناسب با فضای بیشتر صفحه تنظیم می‌شود.

### صفحه بزرگ

Sidebar باریک‌تر و شناورتر می‌شود تا محتوای اصلی بیش از حد پوشانده نشود.

## Overlay و Motion

- Sidebar همیشه از سمت راست باز می‌شود.
- محتوای اصلی زیر Sidebar باقی می‌ماند.
- یک لایه نیمه‌شفاف بین Sidebar و محتوای اصلی قرار می‌گیرد.
- باز و بسته‌شدن Motion کوتاه و کنترل‌شده دارد.
- لمس بیرون Sidebar آن را می‌بندد، مگر زمانی که یک عملیات حساس نیازمند تعامل صریح باشد.

### گفت‌وگوی جدید

در بالای Sidebar و خارج از گروه‌ها قرار می‌گیرد و یک Action اصلی با ظاهر Primary است.

### ابزار

شامل فضای کار، عیب‌یابی و تنظیمات است.

### اطلاعات

فقط شامل «درباره برنامه» است.

### اخیر

«تاریخچه گفتگوها» دکمه جداگانه نیست. پنج گفت‌وگوی اخیر مستقیماً نمایش داده می‌شوند و «مشاهده بیشتر» هر بار پنج گفت‌وگوی دیگر به همان فهرست اضافه می‌کند.

گفت‌وگوی فعلی در ابتدای این بخش قرار دارد و با Highlight ظریف + Indicator مشخص می‌شود.

## تعامل گفتگوها

- کلیک/لمس معمولی → باز کردن گفتگو.
- نگه‌داشتن → منوی عملیات از همان نقطه به سمت پایین باز می‌شود.
- منو شامل «باز کردن»، «تغییر نام» و «حذف» است.
- ساختار بصری منو با منوی سه‌نقطه هدر یکسان است.
- «حذف» با رنگ قرمز معنایی نمایش داده می‌شود.
- حذف فوری است و پیام Undo برای ۱۰ ثانیه نمایش داده می‌شود.
- شمارشگر معکوس کوچک و دکمه `×` برای بستن پیام Undo وجود دارد.

## زبان و جهت

**تمام متن‌های Sidebar باید فارسی و راست‌چین (RTL) باشند.**

## Accessibility

Sidebar باید نقش معنایی مناسب داشته باشد، وضعیت باز/بسته بودن را اعلام کند و مدیریت Focus را هنگام بازشدن و بسته‌شدن رعایت کند.
