# سؤال ۱۱ — تعامل با گفت‌وگوهای اخیر

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم

تعامل با هر گفت‌وگوی موجود در بخش «اخیر» دو رفتار اصلی دارد:

### کلیک

با **کلیک/لمس معمولی** روی گفت‌وگو، همان گفت‌وگو باز می‌شود.

### نگه‌داشتن

با **نگه‌داشتن (Long Press)** روی گفت‌وگو، یک منوی کشویی از همان نقطه باز می‌شود و به سمت پایین امتداد پیدا می‌کند.

```text
┌──────────────────────────────────┐
│ ● بررسی پروژه          ۵ دقیقه پیش│
└──────────────────────────────────┘
                 │
                 ▼
          ┌──────────────┐
          │ باز کردن     │
          │ تغییر نام    │
          │ حذف          │
          └──────────────┘
```

## منوی گفت‌وگو

گزینه‌های منو دقیقاً عبارت‌اند از:

- باز کردن
- تغییر نام
- حذف

### ظاهر منو

ساختار بصری این منو باید از نظر شکل و زبان طراحی با **منوی Premium سه‌نقطه هدر در Q06** یکسان باشد:

- Surface نرم.
- گوشه‌های گرد.
- سایه بسیار ظریف.
- Motion کوتاه و کنترل‌شده.
- بدون Blur سنگین.
- منو از نقطه تعامل همان گفت‌وگو باز شود و به سمت پایین گسترش پیدا کند.

### گزینه حذف

گزینه **«حذف» باید با فونت/رنگ قرمز هشداردهنده** نمایش داده شود تا ماهیت مخرب عملیات از دو گزینه دیگر قابل تشخیص باشد.

رنگ دقیق قرمز در Design System مشخص می‌شود.

## رفتار

- کلیک/لمس معمولی → بازکردن مستقیم گفتگو.
- نگه‌داشتن → بازشدن منوی عملیات از همان نقطه.
- انتخاب «باز کردن» → گفتگو باز می‌شود.
- انتخاب «تغییر نام» → جریان تغییر نام اجرا می‌شود.
- انتخاب «حذف» → جریان حذف گفتگو اجرا می‌شود.
- لمس بیرون منو → منو بسته می‌شود.

## زبان و راست‌چین

تمام متن‌های قابل مشاهده این منو باید **فارسی و راست‌چین (RTL)** باشند.

## Accessibility

- Long Press نباید تنها راه دسترسی به عملیات باشد؛ عملیات باید از مسیر قابل دسترسی دیگری نیز برای فناوری‌های کمکی قابل کشف باشد.
- گزینه حذف باید از نظر معنایی به‌عنوان عملیات مخرب شناخته شود، نه فقط از طریق رنگ.
- وضعیت باز بودن منو باید برای فناوری‌های کمکی اعلام شود.
