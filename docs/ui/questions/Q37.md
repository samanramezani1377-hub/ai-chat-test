# سؤال ۳۷ — رابط کاربری تأیید Action حساس

**وضعیت:** ⏳ در انتظار پاسخ

وقتی یک Action نیازمند تأیید کاربر باشد، کارت/بخش تأیید در UI چگونه نمایش داده شود؟

### A — کنترل کوچک
فقط یک وضعیت کوچک «نیازمند تأیید» و دکمه‌های تأیید/رد نمایش داده شود.

### B — کارت کامل ⭐
جزئیات مهم Action، دلیل تأیید، نتیجه مورد انتظار و دکمه‌های «تأیید» و «رد» در یک Card مستقل نمایش داده شود.

### C — Dialog
تأیید همیشه با Dialog انجام شود و کاربر قبل از اجرا آن را تأیید کند.

### D — داخل فضای کار
Action در همان Timeline/مرحله Workspace متوقف شود و کنترل تأیید همان‌جا قرار بگیرد.

### E — تطبیقی
در حالت عادی تأیید در همان Context فضای کار انجام شود؛ برای Actionهای حساس‌تر یا پرریسک، تأیید صریح‌تر مانند Dialog استفاده شود.
