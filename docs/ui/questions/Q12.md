# سؤال ۱۲ — بازگردانی حذف گفتگو

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم

**گزینه D — حذف فوری + بازگردانی**

پس از انتخاب «حذف»، گفتگو فوراً از فهرست اخیر حذف می‌شود و یک پیام بازگردانی (Undo) برای **۱۰ ثانیه** نمایش داده می‌شود.

```text
╭────────────────────────────────────────╮
│ گفتگو حذف شد     بازگردانی     ۱۰ ×    │
╰────────────────────────────────────────╯
```

## شمارش معکوس

- مدت فرصت بازگردانی: **۱۰ ثانیه**.
- یک شمارشگر کوچک و معکوس در کنار پیام نمایش داده می‌شود.
- شمارشگر باید مینیمال، کوچک و خوانا باشد.
- شمارشگر نباید از پیام اصلی یا Action «بازگردانی» توجه بیشتری بگیرد.
- پس از رسیدن شمارشگر به صفر، پیام خودکار ناپدید می‌شود و Undo دیگر امکان‌پذیر نیست.

## حذف پیام Undo

یک دکمه `×` کوچک در خود پیام وجود دارد تا کاربر بتواند پیام بازگردانی را **پیش از پایان ۱۰ ثانیه** ببندد.

این `×` فقط پیام Undo را می‌بندد و به معنی بازگرداندن یا حذف دوباره گفتگو نیست.

## ظاهر و هماهنگی

پیام Undo باید کاملاً با زبان بصری کلی UI هماهنگ باشد:

- Surface نرم و Premium.
- گوشه‌های گرد.
- Shadow بسیار ظریف.
- Typography مینیمال.
- Motion کوتاه و کنترل‌شده.
- بدون افکت‌های سنگین.
- Action «بازگردانی» واضح و قابل تشخیص.
- شمارشگر و `×` کوچک و غیرمزاحم.

## رفتار

1. کاربر «حذف» را انتخاب می‌کند.
2. گفتگو فوراً از فهرست حذف می‌شود.
3. پیام «گفتگو حذف شد» نمایش داده می‌شود.
4. شمارشگر از ۱۰ شروع به کاهش می‌کند.
5. انتخاب «بازگردانی» → گفتگو دوباره به فهرست بازمی‌گردد.
6. انتخاب `×` → پیام Undo بسته می‌شود؛ گفتگو حذف‌شده باقی می‌ماند.
7. پایان ۱۰ ثانیه → پیام بسته می‌شود و Undo دیگر در دسترس نیست.

## زبان و راست‌چین

تمام متن‌های قابل مشاهده باید **فارسی و راست‌چین (RTL)** باشند.

چیدمان داخلی پیام باید با RTL سازگار باشد، در حالی که شمارشگر و کنترل بستن در جایگاه بصری تعیین‌شده باقی می‌مانند.

## Accessibility

- پیام Undo باید برای فناوری‌های کمکی قابل اعلام باشد.
- «بازگردانی» باید Action قابل دسترس داشته باشد.
- شمارشگر باید معنای زمانی خود را برای فناوری‌های کمکی منتقل کند.
- `×` باید نام دسترسی توصیفی داشته باشد.
- امکان Undo نباید فقط از طریق شمارشگر قابل فهم باشد.
