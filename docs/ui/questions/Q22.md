# سؤال ۲۲ — نمایش وضعیت توقف تولید

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم نهایی

**گزینه C — امکان ادامه**

بعد از انتخاب «توقف»، متن تولیدشده تا لحظه توقف باقی می‌ماند و یک Action کوچک برای **«ادامه تولید»** نمایش داده می‌شود.

## رفتار UI

```text
پاسخ نیمه‌کاره
────────────────────
متن تولیدشده تا لحظه توقف...

تولید متوقف شد
[ ادامه تولید ]
```

پاسخ ناقص حذف نمی‌شود و کاربر می‌تواند از همان پاسخ، تولید را ادامه دهد.

## زبان و راست‌چین

تمام متن‌ها و اجزای این مسیر باید فارسی و راست‌چین (RTL) باشند.

## قفل UI

این تصمیم بخشی از UI Contract است و قبل از کدنویسی نهایی قفل شده است.
