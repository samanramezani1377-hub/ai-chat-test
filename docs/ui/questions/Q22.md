# سؤال ۲۲ — نمایش وضعیت توقف تولید

**وضعیت:** ⏳ در انتظار پاسخ

بعد از انتخاب «توقف»، نتیجه و وضعیت پاسخ چگونه در UI نمایش داده شود؟

### A — پاسخ نیمه‌کاره
متن تولیدشده تا لحظه توقف باقی بماند و یک نشانه کوچک «متوقف شد» نمایش داده شود.

### B — پیام وضعیت جداگانه
پاسخ نیمه‌کاره باقی بماند و زیر آن یک وضعیت مستقل «تولید متوقف شد» نمایش داده شود.

### C — امکان ادامه ⭐
پاسخ نیمه‌کاره باقی بماند و یک Action کوچک برای «ادامه تولید» نیز نمایش داده شود.

### D — حذف پاسخ نیمه‌کاره
با توقف، پاسخ ناقص حذف شود و گفتگو به حالت قبل از تولید برگردد.

### E — ترکیبی
به‌صورت پیش‌فرض پاسخ نیمه‌کاره باقی بماند؛ امکان ادامه یا حذف آن از منوی همان پاسخ فراهم شود.
