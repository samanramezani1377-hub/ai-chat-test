# سؤال ۲۸ — تعامل با Trace و خطاها

**وضعیت:** ⏳ در انتظار پاسخ

در بخش عیب‌یابی، کاربر با Trace و خطاهای یک Execution چه تعاملاتی داشته باشد؟

### A — فقط مشاهده
Trace و خطاها فقط خواندنی باشند.

### B — مشاهده + کپی ⭐
مشاهده جزئیات و کپی متن/جزئیات خطا و Trace امکان‌پذیر باشد.

### C — مشاهده + Retry
علاوه بر مشاهده، Action قابل Retry نیز از همان بخش در دسترس باشد.

### D — مشاهده + Verification
برای مواردی که نیاز به Verification دارند، کنترل تأیید از همان‌جا ارائه شود.

### E — کامل
مشاهده + کپی + Retry + Verification، با نمایش واضح اینکه هر Action چه وضعیتی دارد و چه عملی مجاز است.
