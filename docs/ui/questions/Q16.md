# سؤال ۱۶ — Indicator وضعیت Runtime / AI

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم

**گزینه B — نقطه + انیمیشن در حال کار، با رنگ متفاوت برای هر وضعیت**

Indicator یک نقطه کوچک است که هم‌زمان با وضعیت Runtime رنگ معنایی متفاوت دارد.

## وضعیت‌ها

- **آماده** → نقطه با رنگ وضعیت آماده، ثابت.
- **در حال کار** → نقطه با رنگ مخصوص این وضعیت، همراه با Pulse بسیار ظریف.
- **در حال تولید** → نقطه با رنگ مخصوص این وضعیت، همراه با انیمیشن تنفسی/Pulse ظریف.
- **خارج از دسترس** → نقطه با رنگ مخصوص وضعیت خارج از دسترس، ثابت.
- **خطا** → نقطه با رنگ مخصوص خطا، ثابت و بدون انیمیشن آزاردهنده.

رنگ دقیق هر وضعیت باید در Design System تعریف شود و نباید به‌صورت پراکنده داخل Componentها نوشته شود.

## اصول Motion

- انیمیشن فقط در وضعیت‌هایی که نشان‌دهنده فعالیت Runtime هستند اجرا شود.
- Pulse باید کوتاه، نرم و کم‌دامنه باشد.
- انیمیشن نباید باعث افزایش ارتفاع یا تغییر Layout Header شود.
- در صورت فعال‌بودن تنظیمات کاهش حرکت سیستم، انیمیشن باید کاهش یابد یا حذف شود.

## Accessibility

رنگ Indicator فقط یک نشانه بصری است و **تنها راه تشخیص وضعیت نیست**؛ متن وضعیت نیز همیشه در کنار آن نمایش داده می‌شود.

## زبان و راست‌چین

تمام متن‌های قابل مشاهده فارسی و راست‌چین (RTL) هستند.
