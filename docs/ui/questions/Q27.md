# سؤال ۲۷ — نمایش Action Trace

**وضعیت:** ⏳ در انتظار پاسخ

Trace اجرای Actionها و مراحل داخلی اجرای درخواست در UI چگونه در دسترس باشد؟

### A — فقط عیب‌یابی
Trace کامل فقط در بخش «عیب‌یابی» نمایش داده شود.

### B — داخل فضای کار ⭐
Trace مربوط به اجرای فعلی در فضای کار قابل مشاهده باشد و جزئیات بیشتر در عیب‌یابی قرار بگیرد.

### C — روی هر پیام
برای پاسخ‌هایی که Action داشته‌اند، یک کنترل کوچک برای مشاهده Trace همان پاسخ وجود داشته باشد.

### D — پنل جداگانه
Trace در یک پنل مستقل داخل صفحه گفتگو باز شود.

### E — ترکیبی
خلاصه Trace کنار نتیجه اجرای فعلی و Trace کامل در عیب‌یابی، با امکان بازکردن جزئیات از همان اجرا.
