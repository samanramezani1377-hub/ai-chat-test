## قواعد تصمیم‌گیری

- هر تصمیم مستقل و قابل ردیابی است.
- تعارض بین تصمیم‌ها باید صریحاً بازبینی شود.
- پس از قفل UI، تغییرات نیازمند اصلاح مشخصات و افزایش نسخه هستند.
- در فاز تصمیم‌گیری هیچ کد UI اضافه نمی‌شود.
- CI مرجع تصمیم طراحی نیست.
