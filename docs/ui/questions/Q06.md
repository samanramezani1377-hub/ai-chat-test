# سؤال ۶ — منوی سه‌نقطه

**وضعیت:** 🔒 تصمیم‌گیری شد

## تصمیم

**گزینه B — منوی کشویی Premium**

با لمس `⋯` یک منوی کوچک و هماهنگ با Header مستقیماً در همان ناحیه باز می‌شود.

```text
┌────────────────────┐
│ چت │ کار │ ⋯       │
└────────────────────┘
             │
             ▼
       ┌──────────────┐
       │ گزارش‌ها     │
       │ تنظیمات      │
       └──────────────┘
```

## ظاهر

- Surface نرم.
- گوشه‌های گرد.
- سایه بسیار ظریف.
- Motion کوتاه و کنترل‌شده هنگام باز و بسته‌شدن.
- بدون Blur سنگین.
- هماهنگ با زبان بصری Q01 و Q03.

## محتوا

در نسخه فعلی منوی سه‌نقطه شامل موارد جانبی زیر است:

- گزارش‌ها / Logs
- تنظیمات

موارد اصلی Navigation در Sidebar همبرگری باقی می‌مانند و نباید در این منو تکرار شوند.

## رفتار

- لمس `⋯` منو را باز می‌کند.
- لمس بیرون منو آن را می‌بندد.
- انتخاب هر گزینه منو را می‌بندد و مقصد مربوطه را باز می‌کند.
- در صورت باز بودن منو و اجرای یک Action جدید، وضعیت منو باید بدون ابهام مدیریت شود.

## زبان و RTL

تمام متن‌های قابل مشاهده منو باید **فارسی و راست‌چین (RTL)** باشند.

## Accessibility

- دکمه سه‌نقطه باید نام دسترسی توصیفی داشته باشد.
- منو باید برای پیمایش دسترسی‌پذیر قابل استفاده باشد.
- وضعیت باز/بسته بودن باید برای فناوری‌های کمکی قابل تشخیص باشد.
- انتخاب گزینه نباید فقط با رنگ مشخص شود.
