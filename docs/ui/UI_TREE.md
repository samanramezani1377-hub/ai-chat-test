# درخت مرجع رابط کاربری

**وضعیت:** 🔒 مرجع ساختاری UI v1
**نسخه هدف:** UI v1.0.0

این سند **مرجع ساختار درختی UI** است. `SCREENS.md` جزئیات صفحه‌ها، `NAVIGATION.md` مسیرهای ناوبری، `CONTROLS.md` کنترل‌های متصل به قابلیت‌های واقعی Core و `DESIGN_SYSTEM.md` قواعد بصری را مشخص می‌کنند.

## قرارداد Workspace

Timeline **مرکز بصری** Workspace است. هیچ پنل Contextual مستقل و ثابتی وجود ندارد. اطلاعات Contextual هر Event داخل Expand همان Event قرار می‌گیرد و Expand می‌تواند چند لایه باشد.

```text
Event
└── ▼ جزئیات
    ├── ▼ درخواست
    ├── ▼ پردازش + Trace
    ├── ▼ Preview / Result
    ├── ▼ Verification
    ├── ▼ Recovery
    └── مشاهده جزئیات → Diagnostics / همان Execution
```

کنترل‌های عملیاتی تطبیقی هستند؛ فقط عملیات واقعی و مجاز همان Action/وضعیت نمایش داده می‌شوند. Progress Bar درصدی برای اجرای جاری وجود ندارد.

## قرارداد ارتباطی بین سطوح

```text
Chat
 └── Action Summary
       └── مشاهده جزئیات
              ↓
Workspace
 └── همان Execution / Event
       └── Expand لایه‌ای
              └── مشاهده جزئیات
                     ↓
Diagnostics
 └── گزارش همان Execution
      ├── Trace
      ├── Error
      ├── Verification
      └── Recovery
```

Workspace، Diagnostics و Chat نمایش‌دهنده/تعامل‌کننده‌اند؛ منطق اجرای Action در Core باقی می‌ماند.

## قواعد مرجع

- هر قابلیت UI باید به یک گره مشخص در این درخت نگاشت شود.
- هر کنترل باید پشت Capability/State واقعی باشد.
- هیچ قابلیت ساختگی، Mock یا Placeholder نباید وارد درخت اجرایی UI شود.
- اطلاعات فنی فقط در صورت وجود داده واقعی نمایش داده می‌شوند.
- تمام متن‌های قابل مشاهده فارسی و RTL هستند؛ داده ذاتاً فنی می‌تواند LTR باشد.
- تغییر ساختار اصلی UI باید ابتدا همین سند و سپس اسناد تخصصی مرتبط را به‌روزرسانی کند.
