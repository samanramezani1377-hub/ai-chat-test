# قرارداد ناوبری رابط کاربری

**وضعیت:** 🔒 یکپارچه‌سازی‌شده برای UI v1

> 🔴 **کل UI فارسی و راست‌چین (RTL) است.** داده‌های ذاتاً فنی تنها استثنا هستند.

## ۱. App Shell

Header مدل ناوبری اصلی را تشکیل می‌دهد:

```text
┌──────────────────────────────────────────────────────┐
│ [ گفت‌وگو │ کار │ ⋯ ]    ● آماده      مدل محلی   [ ☰ ] │
└──────────────────────────────────────────────────────┘
```

### ناحیه چپ

- گفت‌وگو
- کار
- ⋯ → لاگ و تنظیمات

گروه کمتر از نصف عرض Header است.

### ناحیه میانی

- وضعیت Runtime محلی
- نمایش دوخطی: وضعیت + «مدل محلی»
- ارتفاع برابر با دکمه‌های Header

### ناحیه راست

- دکمه گرد همبرگری
- بازکردن Sidebar اصلی از سمت راست

## ۲. Sidebar

Sidebar مقصدهای ساختاری برنامه را ارائه می‌کند و از سمت راست باز می‌شود.

```text
Sidebar
├── گفت‌وگوی جدید
├── ابزار
│   ├── فضای کار
│   ├── عیب‌یابی
│   └── تنظیمات
├── اطلاعات
│   └── درباره برنامه
└── اخیر
    ├── گفت‌وگوی فعلی
    ├── گفت‌وگوی ۱
    ├── گفت‌وگوی ۲
    ├── گفت‌وگوی ۳
    ├── گفت‌وگوی ۴
    ├── گفت‌وگوی ۵
    └── مشاهده بیشتر
```

«تاریخچه گفتگوها» مقصد یا دکمه جداگانه نیست؛ تاریخچه به‌صورت مستقیم در «اخیر» نمایش داده می‌شود.

## ۳. رفتار گفتگو

- کلیک/لمس معمولی → بازکردن گفتگو.
- Long Press → منوی عملیات از همان نقطه به سمت پایین.
- عملیات: باز کردن، تغییر نام، حذف.
- منوی عملیات از نظر ظاهر با منوی `⋯` Header یکسان است.
- حذف با رنگ قرمز نمایش داده می‌شود.
- حذف فوری است و Undo به مدت ۱۰ ثانیه در دسترس است.

## ۴. مشاهده بیشتر

فهرست اخیر با ۵ مورد شروع می‌شود. هر انتخاب «مشاهده بیشتر» پنج مورد دیگر را به همان فهرست اضافه می‌کند و کاربر را از Sidebar خارج نمی‌کند.

## ۵. باز و بسته‌شدن

- Overlay نیمه‌شفاف بین Sidebar و محتوای اصلی قرار می‌گیرد.
- لمس بیرون Sidebar آن را می‌بندد، مگر عملیات حساس.
- Motion کوتاه و کنترل‌شده است.
- مدیریت Focus هنگام بازشدن و بسته‌شدن الزامی است.

## ۶. واکنش‌گرایی

- موبایل: Overlay با عرض زیاد و فاصله کم از لبه.
- تبلت: Overlay با عرض متناسب.
- صفحه بزرگ: Sidebar شناورتر و باریک‌تر.

## ۷. زبان

تمام مسیرها، مقصدها، عنوان‌ها، Menuها و Actionهای UI باید فارسی و RTL باشند.
