## نوار ناوبری اصلی

در صفحه‌های اصلی، نوار پایین سه مقصد ثابت دارد: «گفت‌وگو»، «تاریخچه» و «تنظیمات». این نوار فقط در همین سه مقصد نمایش داده می‌شود؛ Voice، Workspace، Diagnostics و About از Sidebar/مسیر بازگشت قابل دسترسی هستند.

## رفتار ناوبری

- ورود عادی به برنامه باید AppDestination.CHAT را نمایش دهد.
- ورود از Wake Word می‌تواند AppDestination.VOICE را باز کند.
- Sidebar از Header در دسترس است و مقصدهای اصلی، ثانویه و گفتگوهای اخیر را فراهم می‌کند.
- تاریخچه کامل یک مقصد مستقل است؛ فهرست اخیر Sidebar فقط میان‌بر است.
- Settings مرکز واحد پیکربندی مدل، Provider، Inference، Context، Agent و Voice است.
- دکمه تنظیمات در صفحه مکالمه صوتی باید به Settings برود؛ تنظیمات مدل صوتی در خود صفحه مکالمه تکرار نمی‌شوند.
- Workspace و Diagnostics مقصدهای تخصصی باقی می‌مانند و نباید با تنظیمات مدل یا Voice مخلوط شوند.
- تغییر مقصد نباید باعث پاک‌شدن Conversation یا پیام‌های ذخیره‌شده شود.
- Back باید ابتدا Overlay/Menu را ببندد و سپس به مقصد قبلی یا Chat برگردد.

## تاریخچه

- عنوان، تعداد پیام، زمان آخرین فعالیت و پیش‌نمایش آخرین پیام نمایش داده می‌شود.
- جستجو در عنوان و متن گفتگوهای بارگذاری‌شده انجام می‌شود.
- فهرست با Paging تدریجی گسترش می‌یابد.
- بازکردن یک مورد، همان Conversation را در Chat بارگذاری می‌کند.
- تغییر نام و حذف از Repository موجود عبور می‌کنند؛ حذف دارای Undo است.

## زبان و دسترس‌پذیری

تمام مسیرها، عنوان‌ها، کنترل‌ها و پیام‌های UI فارسی و RTL هستند. نام مدل، URL، شناسه و کد فنی می‌توانند LTR باشند. Focus، Back، ناحیه لمس، Font Scale و TalkBack باید حفظ شوند.

## سازگاری نسخه

این قرارداد جایگزین ساختار ناوبری UI v1 در تصمیم‌های Q01 تا Q35 می‌شود. آن تصمیم‌ها به‌عنوان تاریخچه طراحی نگهداری می‌شوند و مرجع اجرای UI جدید نیستند.
