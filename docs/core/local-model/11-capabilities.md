# 11 — Capabilities

```text
Model Capabilities
├── import
├── inspect
├── validate
├── list
├── get
├── activate
├── deactivate
├── unload
├── delete
├── runtimeStatus
├── runtimeInfo
└── inference
```

هر Capability باید نتیجه واقعی، State، Error و در عملیات قابل ردیابی، Operation/Execution/Trace ID داشته باشد.
