# 13 — Security

```text
Security
├── File URI Access
├── Persistent URI Permission where required
├── Storage Isolation
├── Input Validation
├── Path / URI Safety
├── Sensitive Metadata Protection
└── No Arbitrary External Execution
```

فایل مدل داده ورودی است و نباید به‌عنوان کد اجرایی تلقی شود. مسیر، URI و metadata باید قبل از استفاده بررسی شوند.
